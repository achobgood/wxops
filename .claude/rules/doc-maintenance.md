# Doc maintenance — which files must change together

When you edit a reference doc, a playbook, a template or a skill, the tables below say which **other** file carries the same fact and must be checked in the same change. They came from wxcc-agent-builder's `CLAUDE.md` (§ Sync Checklist and § Playbook ↔ Reference Doc Pairs) in the Webex Ops merge, Plan 4; each row is verbatim except where a file it named has moved (those rows say so).

This rule is for maintainers of the source repository only. It is excluded from the shipped playbook (`wxcli-dist/assemble.py` `EXCLUDE_FILES`), so a customer folder never loads it. Who **owns** a fact, and why a duplicate keeps its value with an owner note instead of being deleted, is the doc-placement rule (`.claude/rules/doc-placement.md`); this file only lists the pairs. A new reference doc or playbook also gets a line in its folder's `INDEX.md`.

The WxCC interview and build sequence live in `.claude/skills/design-ai-agent/` (Plan 5).

## Sync Checklist

Where two files carry the same fact, the duplicate names its owner inline (`.claude/rules/doc-placement.md` § The Single-Owner Rule) and **that annotation is the tiebreak**. These rows exist so a change to one file prompts a check of the other — they name the pair, not every shared heading. Files with shared sections also carry `<!-- SYNC: ... -->` markers.
